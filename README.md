# Homework 1 - Unix Command-Line Assignment

This repository contains my submission for Homework 1.

The assignment focused on practicing basic Unix command-line operations, including file permissions, pipes, redirection, filtering, sorting, counting, and combining files.

## Contents

- `Homework1_Submission.docx` - My completed Homework 1 submission containing the commands and their outputs.

## Topics Covered

- File permissions using `chmod`
- Listing and filtering files
- Using `head` and `tail`
- Extracting fields with `cut`
- Sorting data
- Counting values with `wc`
- Removing duplicate values with `uniq`
- Text processing with `tr`
- Combining files with `paste`
- Input and output redirection
- Checking command exit status
